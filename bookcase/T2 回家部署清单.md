# T2 回家部署清单

给「联想个人云 T2（非 Pro）」的落地清单。目标：回家后 **30 分钟内**让手机能上传/下载电子书。

## 先记住三件事

1. **T2 官方不支持 Docker。** 联想 2024-12 在社区明确回复「T2 因架构问题，不会支持」；T2 是 Realtek RTD1296（ARM64），T2 Pro 才是 Intel x86。网上 T2 Pro 的 Docker 教程不要往 T2 上套。
2. 你的 T2 只有两条现实路线：
   - **路线 C（推荐，最稳）**：书库跑在一台**按需开机**的 Windows 电脑上，书存进 T2 的 Samba 共享目录。完全不改 NAS，不需要 24 小时开着。
   - **路线 B（NAS 上跑）**：通过「远程协助」开 SSH，确认有 `python3` 后，把书库直接装在 NAS 上。只有这条路线能让你不开电脑也从 NAS 下载。
3. 两条路线都**不会改动你的电子书**；最坏情况删掉书库目录就回滚，书还在。

---

## 你的用法：按需开机就够了

你的主要工作是「整库备份 + 以后按书单下载」，不需要书库一直在线：

- **备份**：开电脑 → 双击 `start-windows.bat` → 手机连同一 Wi-Fi 打开书库 → 右上角 ＋ 全选/按文件夹上传 → 关电脑。书已经落在 T2 的共享目录里，NAS 自己会保存。
- **按书单下载**：开电脑 → 进书单 → 点「下载书单（N）」→ 得到一个 ZIP → 关电脑。
- 书单、标签、阅读进度存在电脑的 `library.db` 里。电脑要重装/换机之前，去设置页点一次「导出整个书架（ZIP）」，`manifest.json` 里带着书单和进度。
- 代价：电脑不开时，手机打不开书库，也不能从网页下载。如果你经常在外地临时想下书，才需要路线 B（跑在 T2 上）或一台常开小设备。

## 三、路线 C：电脑 + Samba（推荐，30 分钟）

### 1. 打开 T2 的 Samba

手机「数据守护者」→【更多应用】→【Samba】→ 打开。默认账号是设备 UID，默认密码 `123456`（管理员可改）。

### 2. Windows 映射网络驱动器

`Win + R` 输入：

```text
\\T2的IP
```

用 UID / 密码登录，找到「个人空间」或你放书的共享文件夹，右键 →「映射网络驱动器」→ 选 `Z:`。

在 `Z:` 里建一个 `电子书` 文件夹（如果还没有）。

### 3. 配置书库

在 `D:\bookcase` 里复制 `config.example.json` 为 `config.json`，改成：

```json
{
  "roots": ["Z:\\电子书"],
  "uploadDir": "Z:\\电子书\\书库上传",
  "trashDir": "Z:\\电子书\\.bookcase-trash",
  "host": "0.0.0.0",
  "port": 8765,
  "token": "换成你的长口令",
  "maxUploadMB": 4096,
  "autoScanMinutes": 10
}
```

注意 JSON 里的反斜杠要写两个：`Z:\\电子书`。`trashDir` 要指向 NAS，这样「归档/回收站」的文件也留在 T2 上。

### 4. 启动

> 先双击 `Z:` 确认网络盘能打开，再启动书库；如果 `Z:` 没挂上，设置页会提示「目录暂时不可用」，不会把项目目录当成书库。

双击 `start-windows.bat`，或命令行：

```powershell
cd D:\bookcase
python -m pip install -r requirements.txt
python server.py
```

第一次启动 Windows 防火墙会弹窗 → 允许「专用网络」。

### 5. 把电脑上的书整批备份（一条命令）

如果书在电脑的某个文件夹里，不用在浏览器里一本本选：

```powershell
cd D:\bookcase
powershell -ExecutionPolicy Bypass -File .\deploy\upload-folder.ps1 -Folder "D:\我的电子书"
```

脚本会读 `config.json` 里的端口和口令，自动递归找电子书、跳过云端已有的、逐个上传。
第一次可以先加 `-DryRun` 看看会传哪些；中途断了直接重跑，已传的会跳过。

手机上的书则用浏览器右上角 ＋ 多选上传。

### 6. 手机验收

1. 手机连家里 Wi-Fi，Chrome 打开 `http://电脑的局域网IP:8765`。
2. 输口令 → 右上角 ＋ → 选一本 epub 上传。
3. 书架出现这本书 → 点开 →「下载到本机」。
4. 建一个书单，放两本书进去 → 点「下载书单（2）」→ 得到一个 zip，解压确认书都在。
5. 浏览器菜单「添加到主屏幕」。
6. 打开「数据守护者」App，看 `电子书/书库上传` 里是否出现刚传的文件（可能需要下拉刷新）。

### 7. 按需开机（不用 24 小时挂着）

- 平时不用设开机自启；要备份/下载时双击 `start-windows.bat`，用完关掉窗口和电脑即可。
- 如果偶尔想让它登录后自动跑：任务计划程序 → 创建任务「登录时运行」→ 程序 `python`，参数 `server.py`，起始于 `D:\bookcase`。
- 长期不开电脑时，书仍然安全地躺在 T2 的共享目录里；下次开机重新扫描即可。

## 四、路线 B：SSH 装到 T2 上（需要 python3）

### 1. 开 SSH（社区方法，有风险）

手机 App【我的】→【远程协助】→ 开启。电脑上：

```bash
ssh admin@T2的IP
cat /opt/conf/user/assist/conf.json     # 里面的 ssh_pwd 是 root 密码
ssh root@T2的IP
passwd root                              # 改成自己的密码
touch /opt/conf/user/enable_ssh          # 永久开启
```

根目录只读时：`mount -o rw,remount /`。

### 2. 检查 Python

```bash
python3 -V
uname -m
```

- `python3` 正常 + `aarch64` → 继续。
- 没有 python3 → 回路线 C。

> 为什么不能从网上直接查？联想没有公开 T2 的软件包清单，固件版本之间也可能不同；同平台的 T1 社区里有人问「怎么装 Python 跑爬虫」，说明原厂大概率没带可用的 Python 3。就算某个版本带了，也可能是 Python 2.7、3.4/3.5，或者缺 `sqlite3` 模块——书库需要 **Python 3.7+**（推荐 3.8+）。所以这一条命令是最快的确认方式，比猜可靠。

### 3. 装书库

建议装到硬盘目录（别放 8GB eMMC），书也放硬盘：

```powershell
# Windows
scp -r .\bookcase root@T2的IP:/sata/.storage/bookcase
```

```bash
# T2
cd /sata/.storage/bookcase
chmod +x start.sh stop.sh deploy/install-ssh.sh
# 轻量模式：不装 PyMuPDF，PDF 只按文件名收录，EPUB 封面正常
INSTALL_PDF=0 BOOKS_DIR=/sata/.storage/books \
  sh deploy/install-ssh.sh /sata/.storage/bookcase
```

记下脚本输出的访问口令。验证：

```bash
curl http://127.0.0.1:8765/api/health
```

### 4. 开机自启

有 systemd：

```bash
cp /sata/.storage/bookcase/deploy/bookcase.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now bookcase
```

没有 systemd 就找 `/etc/rc.local` 或 `/etc/init.d/` 加入 `/sata/.storage/bookcase/start.sh`。固件升级可能重置。

### 5. 负载大不大？

不大。书库是「文件索引 + 小网页」，不是转码/流媒体服务：

| 状态 | CPU | 内存 | 说明 |
| --- | --- | --- | --- |
| 空闲 | <1% | 约 30–50 MB | 只占一个 Python 进程和一个 SQLite 连接 |
| 上传/下载 | 很低 | 约 30–50 MB | 流式读写，不整本进内存 |
| 扫描 EPUB | 单核跑一会儿 | 40–60 MB | 只读 ZIP 元数据和封面 |
| 扫描 PDF（带封面） | 单核 1–3 秒/本 | 80–250 MB 峰值 | 唯一的重活，逐本处理，不会并发 |
| 扫描 PDF（轻量模式） | 很快 | 30–50 MB | 不调用 PyMuPDF，只按文件名收录 |

T2 有 2GB 内存，空闲时书库只占其中很小一部分；真正占资源的是你自己的 Samba 传输和系统服务。建议：

- `INSTALL_PDF=0` 轻量模式；PDF 没有封面，但能下载、能在浏览器里读，EPUB 封面不受影响。
- `autoScanMinutes` 设 0，备份完手动点一次扫描，不让它定时跑。
- `start.sh` 已经用 `nice -n 19` 启动，扫描时不会抢 Samba 的 CPU。
- 书库和书都放 `/sata/.storage`（硬盘），别放 eMMC。

### 6. 手机验收

同路线 C 的第 5 步，地址换成 `http://T2的IP:8765`。

## 六、回滚

- **路线 C**：Ctrl+C 停掉 `python server.py`，删掉 `config.json` 即可；NAS 上只多了你上传的书。
- **路线 B**：`cd /opt/bookcase && sh stop.sh`，然后删掉 `/opt/bookcase`；书在共享目录里，不受影响。
- **Docker（仅 T2 Pro）**：`docker rm -f bookcase`，数据在 `/data` 卷里。

## 七、数据安全

- 原书只读，书库只建索引，不改文件。
- 数据库和封面在 `DATA_DIR`（路线 C 是项目目录，路线 B 是 `/opt/bookcase/data`）。
- 备份 = 拷走 `library.db` + `covers/` + 书目录。
