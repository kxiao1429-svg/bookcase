# 书库 APK 使用说明

书库 v1.12.0（Android，arm64）。点图标就能用，不依赖 DSH / Termux，也不用联网。

## 各版本改了什么

**1.12.0**
- **进度条改为单击呼出**：原来是双击，现在在阅读页底部（进度条原来的位置）**点一次**就出来，
  5 秒不操作自动隐藏。左右两侧仍然是翻页，互不影响。

**1.11.0**
- **阅读进度条**：EPUB 和 PDF 阅读页底部多了一条滑块——EPUB 显示「当前位置 / 总位置」，
  PDF 显示「当前页 / 总页数」。单击底部呼出，5 秒不操作自动隐藏；拖动滑块可以直接跳转。

**1.10.0**
- **书单迁移**：书单页点「迁移」→「导出到文本框」→ 复制；换设备后粘贴 →「导入」。
  书按 文件哈希 → 书名+作者 → 书名 三级匹配，两台设备的目录不一样也能对上，
  导入后会显示「新建 X / 合并 Y / 匹配 Z 本 / 缺失 N 本」。
- 复制走 `navigator.clipboard`（localhost 算安全上下文），失败会退回 `execCommand('copy')`；
  再不行就长按文本框手动全选复制。

**1.9.0**
- **书单封面**：书单卡片上多了相机按钮，可以自定义封面；旁边还有「恢复自动封面」。
- **恢复初始封面**：图书详情页换了封面后，可以一键还原——会优先用换封面时自动备份的原图，
  没有备份就从原书里重新提取。
- **黑夜/白天主题**：设置页多了主题切换，阅读器右上角也能快速切，选择会记住。

**1.8.0**
- **修好了「批量重命名」**：前端发的是 `{action:"renameAll"}`（不带 id），旧代码先解析 id 就返回
  「缺少 id」400，所以一直没生效。现在把 renameAll 提到解析 id 之前处理。

**1.7.0**
- **换封面**：详情页封面右上角多了一个相机按钮，点了从相册选图，自动压到 700px 宽再上传，
  立刻生效、退出重进还是新封面。
- **确认框换成应用内样式**：删除书单、移入回收站、批量重命名改成应用内的确认面板（不再用系统 confirm）。
- APK 侧新增 `WebChromeClient.onShowFileChooser`，WebView 里的 `<input type="file">` 才能弹出选择器。

**1.6.0**
- **修好了返回键/侧滑**：`evaluateJavascript` 回传的是 JSON，字符串会带引号（`"true"`），之前用
  `equals("true")` 判断永远不成立，所以返回键直接退出了 App。现在用 `contains("true")`，返回会按层关闭。
- **启动前先探测 `/api/stats`（1 秒超时）**：服务已经在跑就直接复用，不再起第二个实例，
  二次打开不会报 `Address already in use`。

**1.5.0**
- **PDF 阅读更好用**：点左右两侧屏幕翻页，也可以左右横滑翻页（第一次会提示一次）。
- **修好了「再次打开报 Address already in use」**：退出后再打开时，先探测 8765 上有没有旧服务，有就直接复用，
  不再起第二个实例；Python 侧也加了同样的兜底。
- 合并 2026-11-20 第三版手机源码（含 REBUILD-APK.md 第 4 条）。

**1.4.0**
- **PDF 内置阅读器**：点 PDF 不再跳下载，直接在应用里翻页（pdf.js），退出再进回到上次页码，进度按页记录。
- **返回手势**：右滑/返回键从最上层开始关（详情 → 阅读器 → 书单编辑 → 各标签页），只有书架最外层才退出 App。
- 合并 2026-11-20 第二版手机源码（bookcase-src-20261120 (1).zip，含 REBUILD-APK.md 的三项要求）。

**1.3.0**
- **详情页「分享这本书」**：调系统分享面板，把 epub/pdf 原文件直接发给别人（微信、QQ、蓝牙、网盘都行）。
- **书单页「分享书单」**：把书单里的书打成一个 zip 分享，包里有书、`书单.txt` 书目清单和 `怎么用.txt`。
- **设置页「导入书单包」**：收到 zip 后保存到 Download，点这里就能导入——解压到 `Download/书库导入/` 并自动扫描。
- 分享用的 zip 会存在 `Documents/Bookcase/分享/`，一周前的旧包自动清理。

**1.2.0**
- 合并 2026-11-20 的手机源码（`bbookcase-src-20261120.zip`）：PDF 库缺失时的修复与 1.1.0 里的一致，功能上无回退。
- 设置页底部显示版本号（`Bookcase v1.12.0`），以后反馈问题能直接对版本。

**1.1.0**
- **修好了「很多 epub / pdf 找不到」**：旧版扫到第一个 PDF 就会因为 Android 上没有 PDF 解析库而整次中断，
  排在它后面的书一本都没进书架。现在 PDF 只是没有封面/页数，扫描不会再被打断；单个坏文件也只影响它自己。
- 扫描目录层级从 5 层放宽到 11 层，埋得深的书也能找到。
- 设置页新增 **目录检查**：列出每个目录能读到多少本书，并把「有书但没在扫描范围」的目录列出来，一键添加。
- 每次打开 App 都会在后台**增量重扫**（只比大小和修改时间，很快），新加的书自动出现。

## 一、安装 / 升级

- 新装：把 `书库-1.12.0.apk` 传到手机点开安装，允许「安装未知应用」。
- 从旧版升级：直接覆盖安装即可，签名相同，`/sdcard/Documents/Bookcase/` 里的数据不动。

## 二、第一次打开：授权

书库要扫 `/sdcard/Download` 里的书，第一次会弹出「需要存储权限」：

- 点 **去授权** → 跳到「所有文件访问」页面 → 找到 **书库** → 打开开关 → 返回 App。
- 小米/HyperOS：设置 → 应用设置 → 应用管理 → 书库 → 权限管理 → 所有文件访问。

## 三、书没找全怎么办（重点）

打开 **设置 → 目录检查 → 检查目录**：

- 上面列出当前扫描目录：`xxx 个文件` 说明能读到；`目录不存在或读不到` 说明路径不对或没权限。
- 下面会列出「这些目录里有书，还没加进扫描范围」，点 **添加**，再点 **重新扫描** 即可。
- 想加别的目录，也可以在「扫描目录」里手工输入路径（如 `/sdcard/电子书`）再点添加。

> 微信/QQ 存在 `/sdcard/Android/data/...` 里的文件，Android 11 起任何应用都读不到，得先另存到 Download。

## 四、日常使用

- 首次启动自动扫描；之后每次打开都会后台增量扫一遍。
- 右上角刷新按钮 = 立即重扫 / 检查新书（只列新增）。
- 搜索、按格式/状态/标签筛选、排序。
- EPUB：应用内阅读，翻页、字号、日夜，退出再进回到上次位置。
- PDF：点开在应用内用内置阅读器，点左右两侧或横滑翻页（pdf.js），进度按页保存，退出再进回到上次页码；仍然没有封面和页数（Android 上装不了 PyMuPDF）。系统 WebView 太旧时会自动退回「下载后用阅读器打开」。
- 详情页「移入回收站」：移到 /sdcard/Download/.bookcase-trash，可以手动搬回来。
- 封面右上角「相机」按钮 = **换封面**：从相册选图，自动压到 700px 宽上传，立刻生效。
- 返回手势：右滑/返回键会从最上层开始关（删除确认 → 新书 → 选书 → 书单编辑 → 阅读器 → 详情 → 其它标签页 → 书单筛选），只有书架最外层才退出 App。

## 五、分享和接收

**分享一本书**：点开书 → 详情页最下面 **分享这本书** → 系统分享面板 → 选微信/QQ/蓝牙/网盘。
发出去的就是原文件（epub 或 pdf），对方用任何阅读器都能打开。

**分享一个书单**：打开书单（书架顶部的书单横幅）→ **分享书单** → 等一两秒打包 → 系统分享面板。
包名类似 `社会学入门-12本-20261120.zip`，里面有：

- 每本书的原文件（同名书自动加 (2)、(3)）
- `书单.txt`：书目清单（书名 / 作者 / 原文件名）
- `怎么用.txt`：给接收方看的说明

包会先存到 `/sdcard/Documents/Bookcase/分享/`，一周前的旧包自动清理。

**接收别人的书单包**：把 zip 存到 `Download`（微信里长按文件 →「用其他应用打开」→ 存到手机），
打开书库 → **设置 → 导入书单包 → 查找书单包** → 找到它点 **导入**。
书会解压到 `Download/书库导入/<包名>/`，自动开始扫描，完成就出现在书架上。

## 六、数据在哪（重要）

```
/sdcard/Documents/Bookcase/
├── library.db     书、书单、标签、阅读进度
├── covers/        封面缓存
└── config.json    扫描目录、回收站路径
```

- 在公共目录，卸载重装不会丢，换机/备份直接拷整个 `Bookcase` 文件夹。
- 从手机 DSH 版迁移：把旧的 `bookcase/library.db` 覆盖到 `/sdcard/Documents/Bookcase/library.db`，
  重开 App 即可（书路径都是 `/sdcard/...`，对得上）。
- 找不到旧库也没关系：重扫一次，书和封面都会有，只是阅读进度从头记。

## 七、已知限制

- PDF 没有封面、没有页数：PyMuPDF 在 Android 上没有可用的轮子；EPUB 完全不受影响。
- 只打了 `arm64-v8a`（2020 年后的手机基本都支持）。
- 服务只监听 `127.0.0.1`，电脑/局域网访问不到，这是有意的。
- App 被系统杀掉后服务停止，重新打开会再起（数据库不丢，增量扫很快）。

## 八、重新打包

工程在 `bookcase-android/`，`README.md` 有完整步骤：

```bash
cd bookcase-android
gradle assembleRelease
```

产物 `app/build/outputs/apk/release/app-release.apk`。签名密钥和口令只放在本地
（`keystore.properties` + `app/keystore/`，都不入库，见 README「签名」一节）。
只要沿用同一个 jks，新版本就可以直接覆盖安装、数据保留。
